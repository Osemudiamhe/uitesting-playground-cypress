# UI Testing Playground Cypress Framework

This project contains Cypress tests for https://www.uitestingplayground.com using BDD and POM.

Getting Started
 Requirements
•⁠  ⁠[Node.js](https://nodejs.org/) (version 16+ recommended)
•⁠  ⁠npm (comes with Node.js)
•⁠  ⁠Git

How to run:
Clone the repo, install dependencies, and run tests:
git clone https://github.com/Osemudiamhe/uitesting-playground-cypress.git && \

change directory to your repository name:
cd your-repo-name 

Install dependency
npm install 

Run project
npx cypress run
